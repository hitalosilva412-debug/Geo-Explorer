```
[Crie uma representação ASCII art criativa da região, usando caracteres como
```

---

### 🧭 Legenda
| Símbolo | Representa |
|---------|-----------|
| `~` | Oceano / Mar / Rio |
| `^` | Montanhas / Cordilheiras |
| `#` | Floresta / Vegetação densa |
| `.` | Planície / Savana |
| `*` | Capital |
| `@` | Cidade importante |
