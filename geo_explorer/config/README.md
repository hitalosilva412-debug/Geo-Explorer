# ⚙️ config/

Configurações do GEO Explorer por ambiente.

```
config/
├── dev/    → Desenvolvimento local
├── prod/   → Produção
└── test/   → Testes automatizados
```

## Arquivos de cada ambiente

| Arquivo | Descrição |
|---------|-----------|
| `.env`  | Variáveis de ambiente (não commitar!) |
| `settings.json` | Configurações do serviço |
| `logging.json`  | Configuração de logs |

> ⚠️ Nunca comite arquivos `.env` com credenciais reais!
