# 🔧 scripts/

Scripts utilitários para automação do GEO Explorer.

| Script | Função |
|--------|--------|
| `seed_data.py`    | Popular o banco com dados iniciais |
| `export_json.py`  | Exportar dados para JSON |
| `gerar_relatorio.py` | Gerar relatório de uso |
| `limpar_cache.py` | Limpar arquivos temporários |
| `backup.py`       | Fazer backup dos dados |

## Uso

```bash
python scripts/seed_data.py
python scripts/export_json.py --output DATA/export.json
python scripts/gerar_relatorio.py --mes 2026-08
```
