# 📖 docs/

Documentação completa do GEO Explorer.

```
docs/
├── api/                        → Documentação da API REST
├── guias/                      → Guias de uso e tutoriais
├── exemplos/                   → Exemplos práticos de uso
└── certificados-emitidos/      → Certificados gerados pelos usuários
```

## Documentos disponíveis

| Documento | Descrição |
|-----------|-----------|
| `api/endpoints.md` | Todos os endpoints da API |
| `api/autenticacao.md` | Como autenticar na API |
| `guias/inicio_rapido.md` | Como começar em 5 minutos |
| `guias/slash_commands.md` | Como usar os slash commands |
| `exemplos/curl_examples.md` | Exemplos com curl |
| `exemplos/python_client.md` | Cliente Python de exemplo |

## Gerar documentação

```bash
# Visualizar no browser (requer mkdocs)
pip install mkdocs
mkdocs serve
```
